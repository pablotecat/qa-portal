# Content templates

These files are neutral starting points for QA Chapter Hub records. They provide structure only and do not define company policy, standards, required fields, or approval rules.

1. Copy the closest template into an appropriate directory under `src/content/docs/`.
2. Rename the file using lowercase, hyphen-separated words.
3. Replace every `TODO`, `Placeholder`, and template instruction.
4. Ask an appropriate QA subject-matter owner to validate the content.
5. Run `npm run validate` before requesting review.

Only `title` and `description` are currently required by the portal schema. The governance model for all other metadata is pending team approval.
