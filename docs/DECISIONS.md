# Foundation decisions

## Confirmed for the first release

| Decision | Reason |
| --- | --- |
| Astro with Starlight | Documentation features are available with little custom code |
| Static GitHub Pages deployment | No backend or database is required |
| QA Chapter Hub | Provisional product name selected for team review |
| Generic visual identity | Avoids presenting an unapproved corporate identity |
| English interface and content | Confirmed product requirement |
| Markdown and MDX content | Keeps knowledge versioned and reviewable |
| Pagefind search | Built into Starlight and requires no external service |
| Title and description required | Minimum useful metadata without imposing governance |

## Deliberate constraints

- No backend, database, analytics, external search, or feedback service.
- No `CODEOWNERS`, branch protection, required approvals, or issue templates.
- No real company standards, project URLs, tasks, owners, or recordings invented.
- No binary video or document storage.

## Pending team decisions

- Final name, logo, colors, and corporate design system.
- Taxonomy, controlled tags, area owners, and content states.
- Review, approval, archival, and versioning policies.
- Recording and attachment providers.
- GitHub Issues, Projects, and external repository relationships.
- Analytics, feedback, security, compliance, and additional accessibility requirements.
