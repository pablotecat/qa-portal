## Guide quality bar

Every future guide should make the following visible:

| Field | Why readers need it |
| --- | --- |
| Purpose and audience | Confirm the guide answers the reader's question |
| Prerequisites | Avoid hidden assumptions |
| Owner and status | Make authority and maintenance visible |
| Scope and limitations | Prevent local advice from becoming accidental policy |
| Validation | Explain how the reader can check the outcome |
| Related resources | Connect the guide to standards, tools, and decisions |
