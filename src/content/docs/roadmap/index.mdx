## Record boundaries

This portal should explain initiatives and preserve their context. If GitHub Issues or Projects become the source of truth for execution, records here should link to them rather than duplicate changing task details.

## Proposed record fields

| Field | Purpose |
| --- | --- |
| Problem or opportunity | Explain why the work is being considered |
| Outcome | Describe the intended result without inventing a commitment |
| Scope and exclusions | Keep the proposal bounded |
| Owner | Identify the person or group maintaining the record |
| Status | Use a lifecycle only after the team approves it |
| Dependencies | Expose coordination needs |
| Related tracking | Link to the canonical issue, project, or repository |

Use `proposal-or-roadmap-item.md` for new records. Integration with GitHub Issues or Projects remains a pending decision.
