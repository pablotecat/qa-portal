## Add a practice

Add a new discipline as `testing-practices/<discipline>/index.mdx`. Add focused practices as pages inside that folder, starting from the `testing-practice.md` source template. Add the new section or page to **Practice Library** in `astro.config.mjs`.

Required on day one: a clear title and description. Ownership, status, scope, tags, review dates, and related links are supported but remain optional until the team approves the governance model.
